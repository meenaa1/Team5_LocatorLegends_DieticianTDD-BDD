# Team5_LocatorLegends_DieticianTDD-BDD

This project is an automated testing suite for a Dietician application, utilizing **Test-Driven Development (TDD)** and **Behavior-Driven Development (BDD)** methodologies. It is built using **Playwright** and **JavaScript**.

## 🚀 Tech Stack
* **Automation Tool:** [Playwright](https://playwright.dev/)
* **Language:** JavaScript
* **Framework:** Cucumber/Gherkin (BDD)
* **CI/CD:** GitHub Actions / Jenkins

## 📂 Project Structure
* `/tests`: Contains test scripts and page objects.
* `/.features-gen`: Generated feature files for BDD execution.
* `/utils`: Utility functions and logger configurations.
* `playwright.config.js`: Central configuration for browser environments.


## 🧪 Features Covered

Dashboard Management

Patient Registration/Add Patient Dialog

Edit Patient Details

Pagination Validation
